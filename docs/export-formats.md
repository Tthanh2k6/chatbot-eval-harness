# Quillnote Export Formats

Quillnote allows you to export individual notes or entire notebooks in five export file formats: Markdown (`.md`), PDF (`.pdf`), HTML (`.html`), Plain Text (`.txt`), and Quillnote Archive (`.qna`). Markdown exports use YAML frontmatter to preserve tags, creation timestamps, and author metadata, while storing embedded images in a companion `assets/` folder.

Exporting notes to PDF format is supported on the Plus and Team subscription plans and includes options for A4 or US Letter page sizes, custom page margins, and clickable table-of-contents links. The proprietary Quillnote Archive (`.qna`) format is available on all plans and packages notes, version history, and binary attachments into a single compressed ZIP-based bundle.

Users can run a full account bulk export from Settings > Data & Export up to 3 times per 24-hour period. Bulk exports under 500 MB download immediately in the browser, while larger archives are processed asynchronously in the background and delivered via a secure download link that remains valid for 48 hours.
