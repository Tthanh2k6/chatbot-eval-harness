# Quillnote Keyboard Shortcuts

Quillnote is designed for fast keyboard navigation across desktop and web platforms. Press `Ctrl+K` (or `Cmd+K` on macOS) to open the Quick Switcher and jump to any note by title in milliseconds. Press `Ctrl+Shift+F` (`Cmd+Shift+F` on macOS) to run a global full-text search across all notebooks, tags, and archived notes.

To create a new note immediately from anywhere in the application, press `Ctrl+Alt+N` (`Cmd+Option+N` on macOS). Inside the note editor, press `Ctrl+Shift+L` to insert an interactive checklist item, `Ctrl+/` to open the slash command menu, and `Ctrl+Shift+D` to insert the current ISO date and time stamp at the cursor position.

Writers can toggle Zen Focus Mode for distraction-free writing by pressing `Ctrl+Shift+Z` (or `F11`), which hides the navigation sidebar and formatting toolbar. All keyboard shortcuts can be customized or reset to default bindings in Settings > Keyboard Shortcuts, where advanced users can also enable optional Vim modal keybindings.
